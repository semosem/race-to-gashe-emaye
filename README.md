# Race to Gashe & Emaye's

A small family running game set in the Ethiopian highlands, with Fidel letters to collect along the way.

**Play:** https://race-to-gashe-emaye.vercel.app

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

The game source is `tools/template.html`; run `python3 tools/build.py` to regenerate `index.html` after editing it.
