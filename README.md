# Race to Gashe & Emaye's (የልጅ ልጆች)

A family running game. Pick a runner and race across the Ethiopian highlands to Gashe Kidane and Emaye Tirunesh's house, collecting golden beans and Fidel letters on the way.

- **Runners:** Afomia, Emmu, Eldana, Bethani, Kalkidan, Kiru, and Nahome carrying Meba. Each has a special power.
- **Levels:** Level 1 teaches the ሀ family (ሀ ሁ ሂ ሃ ሄ ህ ሆ), Level 2 the ለ family (ለ ሉ ሊ ላ ሌ ል ሎ). Letters are read aloud when collected.
- **Faces:** "Attach face" on the runner screen puts a photo face on a runner. Photos are stored only in that browser on that device; nothing is uploaded.
- **Controls:** tap or press Space to jump, tap again in the air to double jump. Best played with the phone turned sideways.

It is a static site: plain HTML, CSS and JavaScript with no build step needed to serve it.

## Project layout

| Path | What it is |
|---|---|
| `index.html` | The game, generated by `tools/build.py` (commit it; Vercel serves it as is) |
| `assets/` | Sprite sheets, backgrounds, obstacles and power-ups (WebP), cut from the Stitch designs |
| `fonts/` | Lilita One, Nunito and Noto Sans Ethiopic, bundled so the game works without Google Fonts |
| `icons/`, `manifest.webmanifest` | App icon and "Add to Home Screen" settings |
| `tools/template.html` | The game source to edit |
| `tools/sprites.json` | Frame sizes, chest (name) and face positions for every sprite sheet |
| `tools/extract_sprites.py` | The script that cut the original Stitch sheets into sprites (needs the source images) |

## Making changes

1. Edit `tools/template.html`.
2. Run `python3 tools/build.py` to regenerate `index.html`.
3. Test locally: `python3 -m http.server 8000`, then open http://localhost:8000.
4. Commit and push. Vercel redeploys automatically.

## Deploying on Vercel

1. In Vercel, choose **Add New → Project** and import this GitHub repository.
2. Framework preset: **Other**. Leave the build command and output directory empty.
3. Deploy. Every push to `main` deploys again.

## Adding a letter family

Add an entry to `LEVELS` in `tools/template.html`, for example:

```js
{key:'ሐ',name:'ሐ family',forms:[['ሐ','ḥä','ha'],['ሑ','ḥu','hoo'],['ሒ','ḥi','hee'],['ሓ','ḥa','haa'],['ሔ','ḥe','hay'],['ሕ','ḥə','hih'],['ሖ','ḥo','hoe']]},
```

Each form is `[letter, sound shown on screen, text spoken when no Amharic voice is available]`.
